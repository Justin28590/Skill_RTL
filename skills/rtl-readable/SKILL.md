# 可读 RTL 生成与验证

**接口与功能正确 > 逐周期行为不变 > 实现清晰 > 风格与评分。** 不为评分改接口、增加流水级或放宽测试。

流程：确认契约 → 规划最小实现 → 完整源码与自检 → 编译/展开 → 独立验证 → 限轮修复 → 可读性重构与整项目回退。

## 1. 加载与权限

编写或修改前，先读 [rules.md](rules.md)，再读目标语言参考：

| 语言 | 参考 | 验证路径 |
| --- | --- | --- |
| Verilog | [references/verilog.md](references/verilog.md) | HDL编译 → 独立TB仿真 |
| SystemVerilog | [references/systemverilog.md](references/systemverilog.md) | 确认可用子集 → HDL编译 → 独立TB仿真 |
| Chisel | [references/chisel.md](references/chisel.md) | Scala编译 → 展开/RTL生成 → 接口核对 → HDL编译与独立TB仿真 |

按“用户明确要求 → 工程配置/源码 → 扩展名”确认语言；冲突先问，无线索默认Verilog并说明。TB使用SystemVerilog不意味着DUT要转换语言，普通`.scala`也不一定是Chisel。转换语言需明确授权。

**受控批处理模式：** 每次生成、修复、重构都先调用`read_skill`读取`SKILL.md`，再读取`rules.md`和当前语言参考；三份未读完不能提交源码。规则工具只返回通用部分及所选分支。唯一权限是读取这三份公开文档；不得跟随其他链接、读取工程/测试/配置、执行命令、联网或写文件。构建、验证、评分和回退均由外层控制器执行，模型不得声称已自行验证。文档链接仅供维护者查阅，不扩大工具权限。

Baseline不加载Skill；mock只是显式离线回放，不假装加载Skill、根据反馈推理或代表模型能力。Skill读取记录只证明文档进入上下文，不证明模型遵循全部规则。

**交互式工程任务：** 审查/解释默认只读；验证请求本身不授权修改RTL/TB；修复只做必要改动，风格重构先保存基线并保护用户无关修改。安装、下载、升级依赖和远程任务需授权，不用新模板覆盖已有工程。其他工程使用实际构建入口，当前`run.py`没有任意已有工程的`--rtl`/`--repair`入口。

## 2. 输入隔离与设计契约

模型只能使用公开需求、接口/构造配置、编码规则、上一轮候选，以及裁剪后的**仅候选**编译/展开诊断和粗粒度失败原因。隐藏TB、激励/期望值、参考实现、私有测试标记、原始仿真日志和凭据不得进入生成或修复上下文；不要索取这些信息或整体上传`results/`/构建目录。Chisel构建日志同样需要去除无关路径、环境和测试信息。

实现前确认：

| 契约 | 必须明确 |
| --- | --- |
| 工程 | 语言/库版本、顶层、源码依赖、可信构建/验证入口；Chisel另含构造参数与生成方言 |
| 接口 | 模块/端口名、方向、位宽、符号性、参数及范围；Chisel以实际生成接口为准 |
| 时钟与复位 | 组合或时序、时钟域/采样沿、同步或异步、极性、复位值及与使能/加载的优先级 |
| 功能与时序 | 运算/状态转换、输出延迟、吞吐、保持、脉冲宽度和输入采样条件 |
| 边界与协议 | 进位/截断/回绕/饱和、移位与索引范围、非法状态；ready/valid传输和背压保持 |
| 验证 | 独立TB、测试顶层、成功/失败判据、工具与超时/修复预算 |

缺少会改变可观察行为的信息时，提出具体问题，不凭端口名猜协议或默认复位。批处理契约不充分应交由维护者处理，不能猜隐藏答案。无独立TB时，授权范围内可给未验证候选或审查结论，功能状态只能为`not_run`。

## 3. 完整实现与自检

编码语义以`rules.md`和语言参考为准。先明确必要状态、组合表达式、更新条件及逐周期关系；简单模块不额外引入FSM、握手、参数或流水线。

当前项目交付**单个完整JSON `files` 对象**，每项仅含`path`和`content`；所有顶层、实际子模块及头文件一次交齐。每轮是完整快照，不是补丁，未重新列出的旧文件不会沿用。不得提交占位逻辑、TODO、省略内容、TB、解释、构建脚本或未声明依赖。

- 最多128文件、源码总计2 MB。路径是项目内相对路径，禁止绝对路径、`..`、隐藏段、反斜杠、重复路径及文件/目录冲突；后缀须符合目标语言。
- HDL include须独占一行、使用相对项目根目录的双引号字面量，文件必须随响应提供；允许本地常规宏，禁止宏拼接、外部include及跨层访问。
- 禁止仿真I/O、终止仿真、`force/release/bind/defparam`、VPI/DPI或测试替代实现；HDL系统函数仅允许`$clog2/$signed/$unsigned/$bits`。不读取参考RTL补齐依赖。
- Chisel只交`.scala`，按公开固定构造契约由可信宿主展开；不提交main/App、构建/依赖文件、BlackBox或外部RTL，不手改生成RTL。
- 内部命名和架构可调整，不必复制参考内部结构，但必须保持公开接口与逐周期行为及实际子模块层次。

提交前核对：完整性与依赖；接口/符号性/延迟；中间宽度、进位和截断；驱动/连接与组合赋值完整性；复位/使能优先级；命名、格式和意图注释。**自检不是功能通过证据。** 其他用户工程按已确认的产物协议交付，不将Scala当作HDL源码。

## 4. 验证、修复与回退

### 独立验证

控制器执行：快照/路径检查 → Chisel编译/展开（如适用）→ 仅候选预处理与展开后策略 → 仅公开顶层编译 → 可信TB链接 → 参数/实例化接口/实际层次检查 → 独立仿真。候选宏与TB隔离；缺失设计不能由参考RTL或TB模块补齐。

**所有必需阶段通过、仿真正常退出、全部成功判据/次数满足且完整日志无失败，才算功能通过。** 编译、展开、退出码0、成功字符串或报告存在均不足够。禁止修改TB迎合候选、删除检查、复用旧RTL通过记录或静默放宽策略。有限仿真不证明综合/PPA、形式等价或全状态空间正确。

| 状态 | 含义 |
| --- | --- |
| `passed` | 实际执行并满足该项判据 |
| `failed` | 实际失败，包括非零退出、超时或缺少必需成功标记 |
| `not_run` | 工具/入口缺失、启动失败或前置阶段未通过 |

功能、可选Lint、可读性分别报告。当前项目级Lint未接入，为`not_run`，不是零违规；其他工程只能报告真实运行的检查。

### 限轮修复

先定位失败阶段，再做最小修改并重跑完整验证：

- 策略/语法/类型/宽度错误：依据候选诊断修复，不把工具不支持的合法方言一概当设计错误。
- Chisel编译/展开错误：区分API/插件/依赖与硬件连接/宽度问题，改源码或已授权配置，从编译/展开重跑。
- 接口/功能错误：复核公开参数、复位、边界、优先级、采样和周期关系；超时/缺标记需查本地证据，不直接判通过。
- 工具缺失、模型调用失败或疑似TB/契约冲突：停止猜测，报告证据、阻塞与所需输入；不反复改RTL、换模、自动降级mock或放宽测试。

默认Baseline/Skill均最多2次功能修复、1次低分重构（每项目最多4次候选生成），以实际配置为准，不追加或隐藏调用。两组模型、任务、评分、反馈、验证及预算相同，仅切换Skill加载；源码/对话/回放游标独立。候选次数不等于HTTP请求数，Skill每次候选有加载轮次（默认上限6次HTTP），额外token/耗时单独记录，不声称总成本相同。失败与未运行都是有效结果，不删除失败样本制造提升。

### 可读性重构

按路径排序拼接**候选源码**评分，不评分JSON或将展开RTL当Scala。三种方法分别为`static-heuristic-v1`、`static-sv-heuristic-v1`、`static-chisel-heuristic-v1`；五项权重为命名25、结构25、复杂度20、注释15、风格15。它们是词法启发式，不理解完整语义或注释质量，不代替Lint/人工盲评，也不作跨语言排名；接口即使被扣分仍须保留。

只有功能已通过且分数低于同一阈值（默认95）才重构；无可用分数则跳过。保存通过快照，重新验证和评分，**功能通过且分数严格提高**才接受；生成失败、验证失败/未运行、分数持平或下降，均回退整个项目并停止本次重构循环。Chisel源码与对应RTL成对回退，即使只改注释也不得复用旧验证结论。

## 5. 交付与安全

批处理模型只返回约定的完整源码JSON，报告由控制器生成。交互式交付简述：源码路径、关键接口/时序与假设、实际命令/工具版本/各阶段状态、证据路径、迭代次数与接受/回退理由、剩余限制或阻塞。

`final/`存在不代表功能通过；看`functional_status`、`selected_attempt`和`stop_reason`。Chisel另保留对应`final-rtl/`。保存完整快照、逐文件哈希和本轮验证证据，不混用不同轮次子模块。`skill_loaded`须有三份文档的实际读取证据；`skill_version=tool-v1`是加载协议，文档版本以哈希为准，不回填旧实验。

超时、进程组终止和源码过滤**不是安全沙箱**，也没有完整内存/磁盘配额。Scala构建脚本、插件和展开代码会执行宿主程序。外部不可信HDL/Scala必须另加无网络、无密钥、非特权且有限资源的隔离；不覆盖既有产物或无授权下载依赖。

维护者按需阅读：[运行与费用](../../README.md)、[协议与信任边界](../../docs/项目级生成.md)、[环境依赖](../../docs/环境与依赖.md)、[评分细则](../../docs/源码可读性评分.md)、[验收](../../docs/验收.md)。语言示例只说明写法，不是经人工审核的few-shot数据集，其通过记录不适用于新候选。

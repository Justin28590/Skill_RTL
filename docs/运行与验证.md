# 运行与验证

Skill 优化、模型调用和结果目录见 [README](../README.md)；任务、许可和测试覆盖见[数据集说明](../data/project-rtl/README.md)。以下命令在仓库根目录执行，不调用付费模型。

## 环境准备

| 场景 | 必需依赖 |
| --- | --- |
| 数据检查、评分、CLI | Linux、Python 3.10+ 标准库；无需 Pi、SDK 或模型权重 |
| Verilog / SystemVerilog 验证 | Icarus Verilog、vvp |
| Chisel 验证 | JDK17、sbt1.10.7、Scala2.13.12、Chisel6.5.0、firtool1.62.0 |
| 真实模型生成 | GLM API；配置见 `configs/glm.json`，密钥通过 `GLM_API_KEY` 传入 |

主流程只需要`data/requirements.json`，无需上游快照。下列前两条仅用于维护历史参考材料，主流程直接从`run.py --check-data`开始：

```bash
python3 scripts/project_dataset.py --download  # 联网，校验固定版本与哈希
python3 scripts/project_dataset.py --check-data
python3 run.py --check-data                         # 检查清单支持的全部任务/语言组合和两组运行计划
python3 run.py --task systolic_matmul --check-data  # 仅检查脉动阵列的两组运行计划
python3 run.py --language chisel --check-data       # 也可仅选一种语言
```

`--check-data` 不构建、不联网、不读取密钥，也不证明功能通过。Chisel 工具需显式安装：

```bash
bash scripts/install_chisel_tools.sh  # Linux x86_64，联网、本地安装，无 sudo
source scripts/env.sh
```

首次 Chisel 构建可能下载固定 Maven 依赖；离线运行须保留 `.tools/chisel/cache/`。默认展开超时300秒、JVM最大堆2GB，`chisel_timeout_seconds` 上限600秒。可选 `scripts/install_tools.sh` 只安装 Verilator/Verible，**不安装 Icarus**；当前项目级 Lint 尚未接入。

## 模型请求与失败诊断

通用配置在 `configs/glm.json`，对 Baseline / Skill 使用相同请求参数：

- `max_tokens`为可选项：省略或设置`null`时请求中不发送该字段，没有本地8192隐式默认值；正整数则原样发送。服务端仍有默认值、输出/上下文硬上限及可能共享的推理预算，省略不保证额度更大或消除截断。端点若要求显式值，应按其文档设置支持的正整数；不自动探测或重试付费请求。报告的`generation_metadata.max_tokens_requested`和`token_limit_mode`记录请求方式，不能据此推断服务端实际上限。
- `api_stream=true`：增量接收 SSE，组装正文和工具调用参数；需有完整结束原因及 `[DONE]` 才接受响应。也兼容服务返回普通 JSON；不支持流式请求参数的兼容端点可显式设为 `false`，不会自动多发一次付费请求。
- `api_timeout_seconds=600`：默认600秒，适配完整项目的长推理/输出；这是网络阻塞等待超时，流式读取还在每次读行前检查累计耗时，并非严格的整个任务墙钟上限。返回中的推理只作为接收进度，不写入日志、对话或源码。整个响应限制32 MiB。
- 每个 HTTP 请求开始、每个生成/验证阶段和失败原因均输出到 stderr，stdout 保持最终 JSON；流式接收期间约每30秒显示进度。`agent_trace.json` 原子更新请求状态、首段时间、段数、耗时和脱敏错误码；后续超时不会继承上一工具轮的结束原因。
- API 超时、HTTP 错误、断流、截断、格式错误分别报告；`generation_failures` 是失败生成轮次数，**不是功能失败任务数**，也可能包含已恢复的失败。`last_error_code`、`last_error` 出现在任务报告及 CSV；多组/多语言 JSON 汇总错误分类。
- `usage` 为已观察到的 token 小计；`usage_complete=false` 表示至少一次请求没有返回完整计数。空对象不表示零费用。即使未收到 `[DONE]`，已观察到的 usage 也保留，但不接受源码。

`output_truncated`表示服务返回`finish_reason=length`，无论是否显式设置`max_tokens`都拒绝不完整响应。JSON解析失败意味着正文不符合交付协议；`skill_not_loaded`意味着当前轮未完成必读Skill文档加载。这是三类独立问题，取消token参数不会自动修复后两者，可分别检查本地`response.txt`或`agent_trace.json`，不要将原始日志整体上传。

Skill 组要求端点支持 `tool_choice=required/none`：未读全时强制工具读取，读全后禁止重复调用工具。端点拒绝这些参数时按 HTTP 错误停止，不自动回退为 `auto` 或追加付费请求。每阶段仍受原有 `max_agent_turns` 约束；Baseline 不发送工具参数。

不自动重试网络请求，不自动降级模型、关闭 thinking 或减少 `max_tokens`；网络失败不消耗 RTL 修复预算，不会把未知费用当作零。先检查错误码、网络/服务状态和配置，再决定是否以**新输出目录**重跑。修复/重构失败仍保留之前的完整项目；评分不可用的重构也回退，而不是中断整个批次。这些基础设施参数变化不是 Skill 提升证据，应重新建立同条件对照。

## 工程回归与离线验收

日常只跑与修改相关的测试，正式冻结前跑全量回归，命令见 [tests/README.md](../tests/README.md)。HTTP 响应使用本地模拟；真实 Chisel 集成需显式设置 `RTL_CHISEL_INTEGRATION=1`。缺工具导致的 skip / `not_run` 不算通过。

需要回归历史来源材料及底层编译/验证工具时，执行以下归档脚本。它们不是新需求设计流程，也不能证明新生成的契约或TB正确：

```bash
python3 scripts/project_dataset.py --verify-reference --output artifacts/project-rtl/reference
python3 scripts/verify_project_replay.py --negative-controls --compact --output artifacts/project-rtl/candidate/verilog
python3 scripts/verify_project_replay.py --language systemverilog --negative-controls --compact --output artifacts/project-rtl/candidate/systemverilog
python3 scripts/verify_project_replay.py --language chisel --negative-controls --compact --jobs 1 --output artifacts/project-rtl/candidate/chisel
```

- 参考验证运行锁定原件；候选回放仅复用底层源码/编译/仿真检查，不经过新流程的设计与独立TB生成阶段。回放副本的兼容性改写见[数据集说明](../data/project-rtl/README.md)，不改原件、不放宽候选策略。
- 输出必须是新目录；可用 `--task <ID>` 缩小范围、`--output <新目录>` 改位置。`artifacts/` 不提交 Git；`--compact` 仅清理可重建的构建产物，保留源码、命令、报告和日志。
- 检查本次退出状态、`summary.json`、各任务报告和日志。负向对照只在可信测试侧注入错误，必须成功编译并出现明确功能失败；编译失败、单纯超时或缺标记不算有效对照。
- 修改契约、测试或验证器后重新生成证据，不能只修改旧报告哈希。**离线回放通过率不是模型生成成绩，也不证明 Skill 变好。**

新流程完整协议、冻结文件和分阶段预算见[设计流程](设计流程.md)。设计/验证准备失败会保留报告并记`not_run`；不会退回这些固定TB。

## 仅维护历史数据时需要

- `scripts/prepare_project_generation.py`：再生候选 TB 适配层及 `tasks.json` 的 `generation` 元数据，不重写公开需求；需要 Icarus 和固定 Chisel 工具链。
- `scripts/build_fma_vectors.py`：确定性重建独立 FMA 测试向量；`scripts/build_project_firmware.py`：重建 CPU 固件，另需 LLVM18。公开契约 PDF 转换另需 `pdftotext`。
- `scripts/expand_project_dataset.py`、`scripts/expand_compute_dataset.py`、`scripts/expand_modern_dataset.py`：固定归档导入；`--download` 会联网，校验哈希并保留已锁定的同仓库文件。

执行不可信 HDL/Scala 前，必须另加无网络、无密钥、非特权且有限资源的隔离；超时和源码过滤不是安全沙箱。具体判定与信息边界见[评估规则](评估规则.md)。

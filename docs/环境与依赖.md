# 环境与依赖

| 依赖 | 用途 |
| --- | --- |
| Linux、Python 3.10+标准库 | CLI、HTTP、数据检查、评分与报告，无需Pi/SDK/本地模型权重 |
| Icarus Verilog / vvp | 项目预处理、编译、接口/层次检查及独立仿真 |
| GLM API | 真实生成；默认`glm-5.3`、`thinking=high`，密钥仅通过`GLM_API_KEY` |
| JDK17、sbt1.10.7、firtool1.62.0 | Chisel后端，宿主固定Scala2.13.12 / Chisel6.5.0及编译插件 |
| `pdftotext` | 仅再生公开契约时转换锁定上游PDF |
| LLVM18：clang、ld.lld、llvm-objcopy | 仅重建PicoRV32固件，正常验证使用锁定镜像 |
| Verilator / Verible（可选） | 安装脚本保留；当前项目验证尚未接入Lint，报告`not_run` |

## 检查

```bash
source scripts/env.sh
python3 --version
iverilog -V
vvp -V
python3 run.py --check-data
python3 -m unittest discover -s tests -v
```

不需要API密钥；测试中的模型HTTP为本地模拟，不会真实调用。缺Icarus时仍可检查数据，相关集成测试skip，不能声称功能已验证。mock仅供显式离线测试，不是API失败回退。

## Chisel

工具不自动安装。需要时显式运行：

```bash
bash scripts/install_chisel_tools.sh  # 联网，仅项目本地安装，无sudo
source scripts/env.sh
python3 run.py --language chisel --check-data
RTL_CHISEL_INTEGRATION=1 python3 -m unittest discover -s tests -v
```

安装脚本限定Linux x86_64，校验固定下载哈希。首次展开可能从Maven下载固定依赖到`.tools/chisel/cache/`，离线需提前缓存。`--check-data`不构建、不下载。默认构建超时300秒，JVM最大堆2GB；源码过滤和超时不是安全沙箱。不可信Scala/HDL须额外无网络、无密钥、非特权资源隔离。

## 本地文件与空间

`.tools/`不属于实验数据。`.tools/downloads/`仅为可重新下载的安装包/探测文件，可在安装后清理；保留已安装工具、符号链接及`.tools/chisel/cache/`以维持离线运行。不要把Maven缓存误当成无需保留的下载包。

真实调用、费用预算与输出约定见 [README](../README.md)，完整离线回放见[验收说明](验收.md)。

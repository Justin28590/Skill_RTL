# 实验与交付计划

依据：本地课程选题 PDF（仓库根目录的 `机器学习大作业选题.pdf`，不随Git分发，非运行依赖）。团队3人，课程截止日期 **2026年12月3日**；排期需结合实际启动时间重新确认，不代表完成声明。

## 目标与范围

研究：在模型、任务和反馈预算相同时，加载 RTL 编码 Skill 是否改善可读性，同时保持功能正确。

已实现完整项目生成、独立验证、限轮修复、可读性评分和整项目回退；已接入32个开源IP。正式模型实验、冻结dev/test与人工盲评尚未完成。实现和验收分别见 [README](../README.md) 与[验收说明](验收.md)。

不做模型训练、自动生成隐藏TB、综合/PPA优化或复杂界面；不以扩大案例数替代主实验。

## 实验约定

- **数据**：当前为pilot，15/32项偏密码/散列领域。按来源、共享依赖和算法族隔离开发/测试集，复核公开契约与测试覆盖；不能把同源依赖泄漏到测试集。
- **两组**：Baseline不加载Skill，Skill加载Skill；模型、采样参数、需求、工具链、功能反馈、评分、修复/重构预算及回退规则相同。组间不共享候选或对话。
- **冻结**：正式测试前冻结数据、配置、Skill与评分器。测试后不据结果调规则，不给某组额外机会；相同预算上限不代表实际成本相同。
- **指标**：首次/最终功能通过率、可读性、修复成功率、调用量/token/耗时；同时报告全部样本与功能通过样本，说明失败和缺失结果。项目级Lint未接入，不报告虚构违规数。小规模重复实验应报告波动。
- **盲评**：至少20组同题代码，隐藏组别，由三人独立评价命名、结构、复杂度、注释和风格，统计一致性；不以启发式分数代替人工评价。
- **诚实报告**：不要求Skill必然更好，不删除失败样本制造提升；离线回放不算模型成绩。

## 提交检查

- [ ] Skill可实际调用，附20～30组审核示例。
- [ ] 功能验证、评分、限轮修复及失败回退可复现。
- [ ] 两组等预算实验完成，配置/版本/结果/成本可追溯。
- [ ] 至少20组人工盲评，含一致性、失败案例与局限分析。
- [ ] 报告、PPT及成功生成/自动修复演示齐全。
- [ ] 另一位成员能按文档复现代表性案例。

首次组会确认姓名、模型/费用预算、共享位置和排期；标记完成时附证据并由另一成员复核。

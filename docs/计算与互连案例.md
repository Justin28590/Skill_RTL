# 计算、数据搬运、存储与互连案例

在原有外围接口/密码核基础上，已分两轮接入以下六个不同IP。上一轮为脉动阵列和分组交换，本轮为FMA、DMA、双端口存储及异步流桥，数据集总量从28增至32项。保留所有旧项目；不将尺寸、时钟比例或翻译目标重复计数。

| ID | 原生 / 可选生成语言 | 完整项目边界 |
| --- | --- | --- |
| `systolic_matmul` | SystemVerilog | UINT8二维脉动阵列、输入错位调度、PE乘累加、完成控制 |
| `axis_packet_switch` | Verilog / SystemVerilog | 多端口AXI-Stream路由、整帧仲裁、优先编码与skid缓冲 |
| `fp32_fma` | Verilog / SystemVerilog | binary32融合乘加、规格化、六种舍入和IEEE异常标志 |
| `axi_dma_engine` | Verilog / SystemVerilog | 双向内存/流DMA、描述符、非对齐、突发分割、完成与错误状态 |
| `axi_scratchpad` | Verilog / SystemVerilog | 双端口AXI共享RAM、读写协议/仲裁、独立时钟和输出流水级 |
| `axis_async_bridge` | Verilog / SystemVerilog | 异步帧FIFO、跨时钟域同步、8→32位转换、背压与坏帧丢弃 |

“现代化”指面向加速器/SoC常见的数据通路，并非宣称这些算法刚被发明、上游提交最新，或六项组合成一个已经验证的完整NPU。

## 运行

```bash
source scripts/env.sh
# 本轮四项：纯本地选择/完整性检查，不执行HDL、不调用模型
python3 run.py --task fp32_fma --task axi_dma_engine --task axi_scratchpad \
  --task axis_async_bridge --group Baseline --check-data
# 脉动阵列是原生SystemVerilog，不支持Verilog目标
python3 run.py --language systemverilog --task systolic_matmul --group Baseline --check-data

# 本轮四项参考验证与错误输出对照，不调用模型；输出必须为新目录
python3 scripts/project_dataset.py --verify-reference --task fp32_fma \
  --task axi_dma_engine --task axi_scratchpad --task axis_async_bridge \
  --output /tmp/modern-reference
# 通过与模型候选相同的验证器离线回放
python3 scripts/verify_project_replay.py --task fp32_fma --task axi_dma_engine \
  --task axi_scratchpad --task axis_async_bridge --negative-controls --compact \
  --output /tmp/modern-replay

# 以下命令才会调用模型、消耗额度；先配置GLM_API_KEY
python3 run.py --task fp32_fma --group Skill --output results/fma-skill
python3 run.py --task axi_dma_engine --group Skill --output results/dma-skill
python3 run.py --language systemverilog --task systolic_matmul --group Skill --output results/systolic-skill
```

## 独立验证覆盖

公开接口、参数、数据格式和时序位于`data/project-rtl/specs/<ID>.md`。TB和参考实现不提供给模型。

- **FMA**：`scripts/build_fma_vectors.py`用Python整数与`Fraction`计算精确乘加并独立舍入，未调用宿主浮点、SoftFloat或参考HDL。15组定向和128组固定种子三元组，遍历4种操作和6种舍入，共**3432组**结果/5位异常检查。覆盖融合消去（非“先舍入乘积再加”）、中点、次正规、上/下溢、±0、NaN/Inf。端口是33位recFN，不是直接32位IEEE编码；测试侧独立编码/解码。仅验证binary32及舍入后tininess；舍入后tininess按无限指数范围的目标精度舍入结果判断，而非简单检查最终指数是否为零。
- **DMA**：独立行为AXI从设备，不链接上游RAM。**24读+24写**并行描述符，长度1..129、四种字节偏移、4KiB边界、多突发、总线/流背压、SLVERR/DECERR；逐字节核对读流，每次写后比较完整64KiB内存及未写字节。检查tag、实际长度、keep/last/ID/dest/user和valid保持。ENABLE_SG=0，上游未实现scatter/gather；abort、早到TLAST、在途复位未覆盖。
- **共享存储**：4KiB、32位、两端口时钟周期10/14，**33个16拍写突发、576拍读回**。所有数据先经公开端口初始化，检查跨端口可见性、零/部分/full strobe、同一端口读写仲裁、不同端口并行、响应阻塞稳定性、ID/RLAST和接口复位后数据保留。禁止同地址读写/双写冲突；不声称缓存一致性或原子性。
- **异步流桥**：DEPTH=64、8→32位、帧模式与坏帧丢弃。两套时钟半周期3/5与7/4各**48帧（41好帧+7坏帧）**，覆盖输入快/输出快、长时间阻塞到满、部分末拍、数据/边带、输出阻塞稳定性及协调复位丢弃未完成帧。未覆盖单侧复位、pause、超长帧及满时丢弃模式。
- **脉动阵列**：N=3/4/8各40组，共120组、3560个结果元素；零/单位/置换/全255/非对称/随机输入、输入采样隔离、`3*N-2`完成延迟、单拍完成与复位取消。UINT8不是有符号INT8；无ready，禁止请求重叠。
- **分组交换**：4入2出、32位、双侧skid、轮询及来源ID标记，共192帧；验证竞争路由、背压、每拍数据/边带、整帧不交织、无丢失/重复及复位清空。

`tests/blackbox/modern/`与`tests/blackbox/compute/`是数据集自编黑盒TB，不依赖内部寄存器名。`tests/test_modern_projects.py`额外拒绝错误舍入、错误写掩码、未丢坏帧及缺失头文件；`tests/test_compute_projects.py`拒绝错误符号/转置、缺PE和丢失keep/ID。

这些是有限功能测试，不是穷尽IEEE认证、形式化公平性、物理CDC/亚稳态/STA签核或SRAM工艺宏验证；没有PPA或模型能力成绩，也没有运行上游完整测试套件。
